# Repo conventions

## Purpose
This repo stores VIX-related analysis reports.

## Writing rules for .md files
- No sycophancy. No filler praise, no "great question", no celebratory language.
- State facts and findings directly.
- No emojis unless explicitly requested.
- No hedging phrases like "it might be worth considering" — say what is true or what to do.
- Cite data sources and dates for any numbers.
